# ガチャたこ焼き ガラポンの回し方ページ 要件

## 目的
- お客さんに「ガラポンは1周回すのではなく、**取っ手を2時〜6時の間で往復させる**と玉が出る」ことを、文字を読まなくても分かるように伝える
- 「タコの赤ちゃんを乗せたゆりかごを揺らすイメージ」として見せ、楽しく覚えてもらう

## 前提
| 項目 | 内容 |
|---|---|
| 見る人 | 屋台の前のお客さん（屋台に置いたパソコンの画面に表示する） |
| 技術 | HTML / CSS / JavaScript のみ（フレームワーク・サーバー処理なし） |
| 置き場所 | `public/garapon/`（Vercel で `/garapon/` として公開） |
| イメージカラー | 赤 |
| イラスト | ChatGPT で作成した透過PNG（3枚） |

### 置き場所を `public/garapon/` にした理由（Why）
- Next.js の `public/` に置いたファイルはそのまま静的ファイルとして配信されるため、HTML/CSS/JS だけで作れる
- boothrink と同じ Vercel のデプロイで公開でき、別にデプロイ先を用意しなくてよい
- Redis などは使わないので、チケット機能には影響しない

## 画面構成（パソコンの横長画面、スクロールなしの1画面）
- 外側は赤、中身は赤い枠線つきの白いコンテナにまとめる（全面が赤だと派手すぎて読みにくいため）
- 上: 見出し「ゆりかごみたいに ゆらゆら回してね」
- 中央左: タコの赤ちゃん＋ゆりかご（左右に揺れる）
- 中央右: ガラポン＋取っ手（取っ手が往復する。動く範囲の横に「⇔」を置く）
- 下: 「1周回さずに、取っ手を行ったり来たりさせると 玉が出てくるよ」
- いちばん下: 玉の色と特典
  | 玉 | 特典 |
  |---|---|
  | 赤 | たこ焼き＋2個 |
  | 青 | たこ焼き＋1個 |
  | 黒 | はずれ |

### 「2時・6時」を画面に出さない理由（Why）
- 時計に例えた言い方は、お客さんにはすぐ伝わらない（専門用語に近い）
- 代わりに、取っ手が動く範囲の真ん中に、動く向きに合わせた「⇔」を置く
- 「2時・6時」はコードの中で角度を決めるための基準としてだけ使う

### 横並びにする理由（Why）
- 横長の画面なので、左右に並べると両方を大きく表示できる
- 「ゆりかご → ガラポン」と左から右へ目が動き、見立てがそのまま伝わる

### メディアクエリを使わない理由（Why）
- 表示するのは屋台のパソコン1台だけなので、画面サイズごとにレイアウトを切り替える必要がない
- 大きさは `vh`（画面の高さに対する割合）で指定し、パソコンの解像度が多少違っても1画面に収まるようにする

## 動きの仕様
- 取っ手の角度（時計の文字盤で表した位置。取っ手側から本体を見た向き）
  - 今の取っ手の向き: 約4時
  - 揺らす範囲: 2時 ⇄ 6時（120°）の往復。1周は回さない
  - CSS の角度にすると: 3時を 0° として、2時 = `-30deg`、6時 = `90deg`
- ゆりかごと取っ手は**同じ周期・同じタイミング**で揺らす（「ゆりかご＝取っ手の動き」と結びつけるため）
- 1往復の時間はおよそ2秒（実物で試して調整する）

## 画像（ChatGPT で作成）
| ファイル | 中身 | 回転の中心 |
|---|---|---|
| `images/body.png` | ガラポン本体（取っ手なし）＋台＋受け皿 | 回さない |
| `images/handle.png` | 取っ手だけ。**3時の向き（真横・右向き）** で描く | 左端の丸い軸穴 |
| `images/cradle.png` | ゆりかごに寝ているタコの赤ちゃん（床の板は消してある） | 揺り木のカーブ（円の一部）の円の中心 |

### 画像の加工
- 白い背景のJPG（ゆりかご・取っ手）は、角から繋がる白だけを透明にした。全体の白を消すと、ゆりかごの毛布まで消えるため
- ゆりかごの画像には床の板が描かれていたので消し、床は CSS で描いた動かない板にした。床ごと揺らすと床まで傾いて不自然なため
- 取っ手の軸穴も透明にし、後ろの柱が見えるようにした

### 取っ手を「3時の向き」で描いてもらう理由（Why）
- 画像の向きが 0° になるので、CSS の `rotate(-30deg)`（2時）〜`rotate(90deg)`（6時）がそのまま時計の位置に対応する
- 画像が斜めだと、角度を計算し直す手間がかかり、間違いも起きやすい

## 非機能要件
- 少し離れた場所からでも読める大きい文字と、はっきりした色の組み合わせ（赤の背景に白い文字など）
- 全画面表示（F11）で、マウスカーソルや操作なしで動き続ける
- 屋台でネットが不安定でも表示できるよう、外部のファイルを読み込まない（画像・CSS・JSはすべて `public/garapon/` 内に置く）
- 個人情報は扱わない
